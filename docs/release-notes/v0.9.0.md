# Mac2Hog 0.9.0 — Millumin control

Mac2Hog can now drive **Millumin** next to your Hog: cues send OSC to both, so lighting and video run from the
same song timecode or the same GO. This release also adds *Duplicate to playhead* in the cue list.

## What's new

### 🎬 Millumin over OSC
- **Settings › Network › Millumin**: Millumin IP / hostname, OSC input port, live status, *Apply* and
  *Send test message* (sends `/m2h/test 1`).
- **Settings › OSC › Millumin Message Format**: address prefix (default `/m2h`), number format
  (float / integer / string) and optional key release (a value of `1` is followed by `0`).
- **New cue command "Millumin Custom OSC"** (cue inspector › *+ Add*, also available for predefined triggers):
  - **Prefix**: empty uses the prefix from Settings
  - **Topic**: empty uses `/millumin`
  - **Value**: text (`start`) or a number (`1`, `0.5` or `0,5`)
  - Example: Topic `/millumin` + Value `start` sends **`/m2h/millumin start`** to Millumin.
- Millumin commands support everything other commands do: Timecode / Follow / Wait cues, Manual GO, setlist
  states and predefined triggers. Millumin uses the network adapter chosen in *Settings › Hardware*.

### 🎚️ Cue list
- **Duplicate to playhead**: copies the selected cue ("Copy of …", with all its commands) to a new cue at the
  current playhead position. In setlist Starting / Waiting / Ending states it duplicates directly below.

### ✏️ Clearer settings
- The Hog OSC settings are labelled as such: *Hog Message Format*, *Hog address prefix*, *Hog number arguments*,
  *Hog goto cue format* and *Hog Goto Cue Test*.

### 🛠️ Under the hood
- Builds and releases run on a self-hosted Mac, building outside iCloud-synced folders so code signing is reliable.
- Removed a compiler warning in the waveform drawing.

## Upgrading from 0.7.0

Replace **Mac2Hog.app** in your Applications folder. Shows, setlists, predefined triggers and settings are kept.
Millumin starts out pointing at `127.0.0.1:5000`; change it in *Settings › Network › Millumin* if Millumin runs
on another computer or port.

## Install

1. Download **`Mac2Hog-0.9.0-macOS.zip`** below and unzip it.
2. Move **Mac2Hog.app** to your Applications folder.
3. This build is not notarized by Apple. The first time, **right-click Mac2Hog.app › Open › Open**.
   If macOS says the app is damaged, run this once in Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Mac2Hog.app
   ```
4. Allow **local network access** when macOS asks, so Mac2Hog can reach the console and Millumin.

**Requirements:** macOS 13 Ventura or later. A Hog console or Hog PC with OSC input enabled (default port 7001)
and, optionally, Millumin with OSC input enabled.
