# Mac2Hog 0.7.0 — first public release

**Mac2Hog turns a song into a light show on a Hog lighting console.** Import a `.wav` or `.mp3`, let Mac2Hog find
the tempo, beats, snare hits, breaks and song parts, attach your Hog cuelists, scenes and macros to cues on the
song's timecode, and run the show over OSC — automatically on timecode, or cue by cue with a big GO button.
Build a whole setlist, with lighting states before, between and after the songs.

## Highlights

### 🎵 Song analysis
- Suggested main tempo (with alternatives, ×2 / ÷2, or type your own), beat grid and bar numbers
- **Snare hits**, kicks, **breaks** and **song parts** (intro, verse, build-up, chorus/drop, break, bridge, outro)
- SMPTE **timecode** for the whole song (24, 25, 29.97 drop-frame or 30 fps, e.g. starting at 01:00:00:00)
- Zoomable waveform with sections, breaks, beat grid and snare markers — pinch to zoom, swipe to scroll

### 🎚️ Cues and Hog commands
- Add cues by double-clicking the waveform, or generate them from song parts, breaks, snares or every _n_ bars
- Commands: Go / Goto Cue / Halt / Resume / Release for cuelists, scenes and macros, master Go / Pause / Back /
  fader, main Go / Halt / Back, or any custom OSC message
- **Import your Hog XML** export to pick cuelists, cues, scenes and macros by name
- Cue start modes **Timecode**, **Follow +n s** and **Wait +n s**, plus a cue Duration
- One-click **Release** of a cuelist or scene after its Go, with its own Follow / Wait timing
- **Predefined triggers** for commands you use again and again

### ▶️ Running the show
- **Timecode mode**: press PLAY and every cue fires on time; latency compensation available
- **Manual mode**: a cue stack with a big **GO** (Space), Follow / Wait chains fire automatically
- Cue list follows along: last fired cue in purple, running cues in red, the next cue blinking green
- Live OSC log, optional Hog OSC feedback

### 📋 Setlists
- Several songs in order (drag to reorder, rename), each with its own analysis, timecode and cues
- **Starting**, **Waiting** (between songs) and **Ending** light states
- Per-song pause, automatic start of the next song, and auto-save after every change

### 🔌 Hardware
- Choose the **audio output** for the song and a separate output and channel for live **LTC timecode**
  (for the Hog's LTC input)
- Choose the **network adapter** (Ethernet / Wi-Fi) used for OSC, with a same-subnet check

## Install

1. Download **`Mac2Hog-0.7.0-macOS.zip`** below and unzip it.
2. Move **Mac2Hog.app** to your Applications folder.
3. This build is not notarized by Apple. The first time, **right-click Mac2Hog.app › Open › Open**.
   If macOS says the app is damaged, run this once in Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Mac2Hog.app
   ```
4. Allow **local network access** when macOS asks, so Mac2Hog can reach the console.

**Requirements:** macOS 13 Ventura or later (Apple silicon or Intel), and a Hog console or Hog PC with OSC input
enabled on the same network (default port 7001).

## Getting started

1. **Settings › Network**: enter the console's IP address and OSC port, then click *Send test message*.
2. **File › Import Hog XML…**: load the cuelist/scene/macro export from your show.
3. On the start screen choose **Single Song** or **Setlist** and import your audio.
4. Click **Generate Cues** (or double-click the waveform), attach Hog commands in the inspector, and press **PLAY**.

The [README](https://github.com/Frankvandetechniek/Mac2Hog#readme) has the full workflow and the Hog OSC mapping.

## Notes and known limitations

- Native Hog `.shw` show files are a proprietary database; export cuelists / scenes / macros to **XML** in Hog OS
  and import that instead.
- Song analysis is a starting point: check tempo, snares and song parts by ear and adjust markers where needed.
- The Hog's exact "go to cue" OSC format can differ between Hog OS versions; *Settings › OSC › Goto cue test*
  lets you pick the one your console accepts.
